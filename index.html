Aturan Firewall

Aturan menentukan apakah sebuah paket diizinkan atau diblokir. Aturan baru langsung dipakai oleh simulasi.

Urutan Keputusan Firewall

Setiap koneksi diperiksa dari kiri ke kanan. Keputusan pertama yang cocok langsung dipakai.

1Firewall

Nonaktif → diizinkan (dengan peringatan).

2Blacklist

IP ada di blacklist → diblokir.

3Aturan BLOCK

IP + port cocok aturan blokir → diblokir.

4Aturan ALLOW

IP + port cocok aturan izinkan → diizinkan.

5Default

Tidak ada yang cocok → diizinkan.

Tambah Aturan Baru

Isi 0.0.0.0 pada kolom IP untuk berlaku ke semua alamat IP.
